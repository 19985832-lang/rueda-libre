# Rueda Libre

Sitio estático para taller de bicicletas con reserva, menú móvil, FAQ, planos y formulario.

## Deploy en Netlify

1. Ve a https://app.netlify.com/
2. Haz clic en "Add new site" > "Import an existing project"
3. Conecta tu repositorio de GitHub: `19985832-lang/rueda-libre`
4. Configura:
   - Branch: `main`
   - Publish directory: `.`
   - Build command: dejar vacío
5. Publica el sitio

La URL final será algo como:
`https://nombre-aleatorio.netlify.app`

## Archivos principales
- `index.html`
- `style.css`
- `script.js`
